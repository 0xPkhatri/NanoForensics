# NanoForensics architecture images

Two coordinated landscape diagrams, generated with the built-in image-generation tool from the current local implementation:

- `nanoforensics-scientific-workflow.png`: scientific investigation, measured physics, independent verification and traceability.
- `nanoforensics-technical-architecture.png`: Next.js, FastAPI, durable worker jobs, structured Muse Spark calls/visible fallback, LAMMPS/NumPy and separate SQLite workspaces.

These are explanatory illustrations, not measured datasets or deployment screenshots. The workflow plot is explicitly schematic. The actual local architecture is shown; cloud hosting is not assumed.
